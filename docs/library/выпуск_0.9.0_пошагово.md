# Первый выпуск drakon-graf 0.9.0 в npm — пошагово (Windows)

*Для С. Н. Веснина. Делается один раз. Дальнейшие версии выпускает GitHub сам (часть 5).*

Как пользоваться: делайте части по порядку. В конце каждой части есть **«Что должно получиться»**. Если вывод другой — ничего не делайте дальше, пришлите в чат снимок экрана или текст вывода.

Все команды вводятся в **«Командной строке»** Windows (не PowerShell — в нём `npm` иногда не запускается из-за настроек безопасности). Открыть: кнопка «Пуск» → наберите `cmd` → «Командная строка». Команду вставляют правой кнопкой мыши и нажимают Enter.

---

## Часть 1. Проверить, что на компьютере есть Node.js и Git

1. Откройте «Командную строку».
2. Введите по одной:
   ```
   node -v
   npm -v
   git --version
   ```

**Что должно получиться:** три строки вроде `v22.12.0`, `10.9.0`, `git version 2.47.0.windows.1`. Первая цифра у `node` — **20 или больше**.

**Если «не является внутренней или внешней командой»:**
- нет Node.js → скачайте **LTS** с https://nodejs.org (кнопка «Download Node.js (LTS)», файл `.msi`), установите со всеми настройками по умолчанию, **закройте и снова откройте** «Командную строку»;
- нет Git → https://git-scm.com/download/win, установка с настройками по умолчанию, затем снова откройте «Командную строку».

---

## Часть 2. Скачать проект и проверить пакет

3. Перейдите в «Документы» и скачайте проект:
   ```
   cd %USERPROFILE%\Documents
   git clone https://github.com/Scatik146/drakon-graf.git
   cd drakon-graf
   ```
4. Установите всё нужное для сборки (1–3 минуты; жёлтые предупреждения `npm warn` — это нормально):
   ```
   npm install
   ```
5. Посмотрите, что попадёт в пакет (ничего не публикуется — только проверка):
   ```
   npm pack --dry-run
   ```

**Что должно получиться** в конце вывода:
```
npm notice name: drakon-graf
npm notice version: 0.9.0
npm notice package size: 1.3 MB
npm notice total files: 45
```
Число файлов может отличаться на 1–2, а имя и версия — нет. Красных строк `npm error` быть не должно.

---

## Часть 3. Войти в npm

6. ```
   npm login
   ```
   npm напишет `Press ENTER to open in the browser...` — нажмите Enter. Откроется сайт npmjs.com: войдите своим логином и паролем и подтвердите вход кодом двухфакторной защиты (из приложения-аутентификатора или ключом). Вернитесь в «Командную строку».
7. Проверьте, что вход удался:
   ```
   npm whoami
   ```

**Что должно получиться:** `npm whoami` выводит ваше имя пользователя npm.

---

## Часть 4. Опубликовать

8. ```
   npm publish --access public
   ```
   Сначала пакет соберётся (строки `dist/drakon-graf.js…` и `fonts/: …`). Потом npm попросит подтверждение двухфакторной защиты — либо откроет браузер, либо спросит `Enter one-time password:` — введите 6 цифр из приложения-аутентификатора.

**Что должно получиться:** последняя строка
```
+ drakon-graf@0.9.0
```
9. Откройте https://www.npmjs.com/package/drakon-graf — там должна быть страница пакета с версией 0.9.0.

**Если ошибка:**
- `E403 … You do not have permission` или `name too similar` — пришлите текст, ничего не меняйте;
- `EOTP` — код устарел, повторите шаг 8 и введите свежий код.

---

## Часть 5. Включить автоматический выпуск (без токенов)

После этого новые версии публикует GitHub сам: сначала все проверки, потом выпуск. Никаких ключей и паролей в GitHub хранить не нужно.

10. На странице пакета https://www.npmjs.com/package/drakon-graf откройте вкладку **Settings**.
11. Раздел **Trusted Publisher** → кнопка **GitHub Actions**. Заполните:
    | Поле | Значение |
    |---|---|
    | Organization or user | `Scatik146` |
    | Repository | `drakon-graf` |
    | Workflow filename | `publish.yml` |
    | Environment name | *(оставить пустым)* |

    Нажмите **Set up connection** (или **Save**).
12. Там же, раздел **Publishing access** → выберите **Require two-factor authentication and disallow tokens** → **Update Package Settings**. Так пакет нельзя будет выпустить украденным токеном.

**Что должно получиться:** в Settings виден Trusted Publisher с `Scatik146/drakon-graf` и `publish.yml`.

## Как потом выпускать новые версии

1. В `package.json` и `src/api.js` поменять версию (например, `0.9.1`) — это делаю я в репозитории.
2. GitHub → репозиторий → **Releases** → **Draft a new release** → **Choose a tag** → ввести `v0.9.1` → **Create new tag** → **Publish release**.
3. GitHub сам запустит «Выпуск в npm»: прогонит все проверки и опубликует. Результат — во вкладке **Actions**.
