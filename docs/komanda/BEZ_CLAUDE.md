# Если Claude недоступен (до двух месяцев): как команда работает сама

Вся память проекта — в GitHub, не в Claude. Качество держат **автоматические проверки** и **рецензент**, а не один исполнитель.

## Роли

| Кто | Роль | Что делает |
|---|---|---|
| **Учитель** | заказчик и последнее слово | ставит цель, сливает Pull Request (PR), решает спорное |
| **Алиса** | координатор | держит процесс: из цели учителя пишет задание по шаблону, ведёт `SOSTOYANIE.md` и журнал решений |
| **DeepSeek** | программист | выполняет задание через GitHub Actions → PR |
| **GLM** | эксперт и рецензент (вместо Claude) | проверяет PR по `CLAUDE.md`, навыкам и заданию: «сливать / вернуть с замечаниями» |
| **Qwen** | контент | тексты, примеры, задачи, черновики конспектов; проверка — Алиса и учитель |

## Цикл одной задачи

1. **Учитель → Алиса:** цель в двух-трёх фразах.
2. **Алиса** пишет задание по `teacher-workpad/docs/komanda/zadaniya/SHABLON.md`. В «Можно менять» — только нужные файлы, в «Готово, когда» — проверка командой. Учитель кладёт файл в `docs/komanda/zadaniya/`.
3. **Учитель:** GitHub → Actions → «DeepSeek: выполнить задание» → Run workflow (файл задания; модель `deepseek-flash`, для сложного — `deepseek-v4-pro`).
4. Через пару минут появляется PR с отчётом DeepSeek и результатом проверок. Отдельно на PR запускается «Проверка».
5. **GLM** получает: промпт рецензента (ниже) + текст задания + изменения из PR (вкладка Files changed или ссылка `…/pull/N.diff`).
6. **Учитель** сливает, если проверки зелёные и GLM говорит «сливать». Иначе: замечания GLM дописать в задание и запустить снова.
7. **Алиса** обновляет `SOSTOYANIE.md` (страница), журнал решений `README.md`, раздел 4, и строкой — журнал брифинга `BRIFING.md` под датой. День начинается с брифинга: без Claude его ведёт Алиса.

**Правило:** красная «Проверка» — не сливать, даже если «вроде работает».

## Промпты ролей

Готовые тексты — в папке `vstavka/` (оглавление `vstavka/README.md`): `alisa-koordinator.md` (Алиса — в режиме эксперта), `glm-recenzent.md`, `qwen-kontent.md`, `deepseek.md`. Меняем промпты только там, чтобы не было двух версий.

## Что нельзя без Claude (лучше отложить)
- Менять язык ДРАКОН-ГРАФ и формат дракон-схем (синтаксис, канон) — только записать предложение в «Открытые вопросы».
- Крупные переделки библиотек (`drakon-graf`, `lib/drakon-shema`) за один PR. Делить на маленькие задания с тестами.

## Деньги
DeepSeek API — предоплаченный баланс на platform.deepseek.com, ключ — секрет `DEEPSEEK_API_KEY` в настройках репозитория (Settings → Secrets → Actions). Одно задание на `deepseek-flash` стоит порядка нескольких центов.
