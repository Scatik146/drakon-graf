# Вставка — тексты для чатов помощников

Каждый файл — **готовый текст**: открыть, нажать «Copy raw file» (значок копирования над текстом справа), вставить первым сообщением в новый чат. Ничего не дописывать.

## Задачи дня — папка `den/<дата>/`
Файлы по номерам; в имени — кому вставлять. `0-…` — Алисе, `1-…`, `2-…` — по порядку.

## Постоянные роли
| Файл | Куда вставить |
|---|---|
| `alisa-koordinator.md` | Алиса — **сначала включить режим эксперта** |
| `glm-recenzent.md` | GLM, затем вставить задание, diff и результат проверок |
| `qwen-kontent.md` | Qwen, затем вставить задание |
| `deepseek.md` | не вставляется — как запустить DeepSeek через GitHub |
| `claude/01-brifing.md` | Claude, начало дня |
| `claude/02-rabochij-chat.md` | Claude, шаблон рабочего чата (заполнить `<…>`) |

Правило: тексты пишем так, чтобы их можно было вставить в любой ИИ — ссылки на файлы прямые (raw), а если ИИ не открывает ссылки, он просит вставить текст.
