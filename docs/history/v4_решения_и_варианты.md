## 2. Вопрос 5: что важнее в одной строке

**Проблема.** Строки вроде `- Термин -> ответ`, `1. x -> y`, `A >< B -> C` можно понять по-разному.

**Принцип: тип строки решает её начало.** Разбор идёт в три шага, и первый подошедший побеждает:

| Шаг | Что смотрим | Пример | Итог |
|---|---|---|---|
| 1 | **Ключевое слово** в начале: `тема:`, `правило …:`, `пример:`… | `пример: a -> b` | пример, `->` — его текст |
| 2 | **Маркер** в начале: `- `, `1. `, `* `, `\| `, `} `, `$$`, знак выкладки | `- Плавление -> в жидкое` | пункт; `->` показан как текст «→» **и выдаётся подсказка** |
| 3 | **Оператор** внутри строки: сначала `><`, потом `->` | `A >< B`, `A -> B` | сравнение или запоминатель |

**Остальные правила:**
- Если в строке и `><`, и `->`, побеждает сравнение, а программа подсказывает.
- В ячейке Шеренги `->` не работает. Нужна буквальная стрелка — `\->` или «→».
- Внутри `$…$` и `` `…` `` операторы не ищутся никогда.

Я рассматривал два варианта.

| | **А. Маркер сильнее оператора** (рекомендую, сделано) | Б. Оператор сильнее маркера |
|---|---|---|
| `- Плавление -> в жидкое` | пункт с текстом «Плавление → в жидкое» + подсказка | запоминатель, маркер `-` выброшен |
| Плюс | Предсказуемо: «что в начале строки, то и есть». Тот же принцип, что в Markdown и Python | Меньше подсказок |
| Минус | Нужна подсказка, если ученик хотел запоминатель | Стрелку в тексте пункта не написать без экранирования; маркер «исчезает» — сюрприз |

## 3. Вопрос 6: что может стоять внутри чего

Варианты:

| | Суть | Плюс | Минус |
|---|---|---|---|
| А. Строгая таблица | Для каждой пары «родитель — ребёнок» явно «можно» или «нельзя» | Полная формальность | Таблица 17×17, детям не объяснить |
| **Б. «Фигура и её содержимое»** (рекомендую, сделано) | Три класса строк: **фигуры** (уровень зоны), **содержимое фигуры** (внутри) и **привесы** (висят под фигурой). Плюс два особых случая: группа и пример | Объясняется одной фразой; формализуется маленькой таблицей | Редкие сочетания (выноска внутри выноски) запрещены |
| В. Свободно | Всё можно, программа делает что сможет | Ноль правил | Непредсказуемый рисунок, ошибки молча проглатываются |

**Вариант Б — правило для детей:** *«На верхнем уровне — фигуры. С отступом под фигурой — её содержимое или то, что к ней привешено».*

| Родитель | Что можно вписать с отступом |
|---|---|
| Зона (без отступа) | `тема:` `связка:` запоминатель, сравнение `><`, пункт, группа, `правило:` `пример:` `контрпример:` `стрелка:` `рисунок:` `код` `выноска:`, маркеры для сравнения списков |
| `тема:` | `выноска:` `уточнение:` |
| запоминатель, пункт | **содержимое:** текст, `*` `\|` `}` `$$` `код` `рисунок:`; **привесы:** `выноска:` `уточнение:` `пример:` `контрпример:` `правило:`; у пункта ещё подпункты |
| группа | пункты, группы (так получается Дерево), маркеры, `выноска:` `пример:` |
| `пример:` | строки выкладки, `связь`, `код`, `$$` |
| `правило:` `выноска:` | содержимое (текст, маркеры, формулы) |
| сравнение `><` | маркеры `* л:` / `* п:` |
| `связка:` `стрелка:` `рисунок:` `код` `связь` | ничего |

Если правило нарушено, программа пишет, например: «„пункт“ не может стоять внутри „стрелка:“ — проверьте отступ». Строку она пропускает, остальное рисует.

## 4. Вопрос 7: обоснования в выкладке

**Как сделано:**

```
пример: 3(x − 2) = x + 4
  = 3x − 6 = x + 4      {раскрыли скобки}
  => 2x = 10            {перенесли с другим знаком}
  => x = 5              {разделили на 2}
```

- **Строка выкладки** — строка с отступом под `пример:`, начинающаяся со знака отношения и пробела: `=`, `=>` (⇒), `<=>` (⇔), `<`, `>`, `<=` (≤), `>=` (≥), `!=` (≠), `≈`, `→`. Знаки можно печатать на английской раскладке, программа рисует правильные символы. Новых слов нет.
- **Первая строка** — то, что стоит после `пример:`.
- **Обоснование** — `{…}` в самом конце строки. Знаки выстраиваются столбиком, обоснования — колонкой справа курсивом за тонкой чертой. Длинные обоснования переносятся.
- Работает и в сцене, и внутри запоминателя: там выкладка рисуется белой вкладкой.

**Почему `{…}` в конце, а не `}.`** Конфликта с разбором `[часть]{подпись}` нет: подпись разбора всегда идёт сразу после `]`, а обоснование стоит после пробела в конце строки. Программа их различает, точка не нужна. Точка в конце строки ещё и путалась бы с концом предложения: «x = 5.» — это точка или знак?

Если всё же хочется явного знака, есть запасной вариант: обоснование через ` // ` («x = 5 // разделили на 2»). Но `//` в Python — целочисленное деление, на уроках информатики это будет путать. Не рекомендую.

**Что выкладка не умеет (пока):**
- разбор `[…]{…}` внутри строки выкладки;
- выравнивание по знаку внутри длинной строки (как `align` в LaTeX): выравнивается только знак в начале.

Для 5–11 классов этого хватает.

## 6. Исправления по вашим замечаниям

### 6.1. Пример больше не рвётся

Было `12          345          678`, потому что строка раздвигалась под ширину подписей. Теперь **текст примера никогда не раздвигается**, а подписи раскладываются по рядам:
- подпись встаёт в ряд, только если не налезает на соседей и **не закрывает хвост** другой подписи;
- хвосты вертикальные, ничего не пересекают.

Цена — при плотном примере подписи идут «лесенкой» в 2–3 ряда. Сами подписи короткие, так что это читается.

### 6.2. Стрелка в пустое место

Новая форма разбора — **пустые скобки `[]`**: невидимая «точка» в тексте. На рисунке это тонкая пунктирная черта. На неё можно навести стрелку правила или повесить подпись:

```
правило → промежуток: Между классами оставляют небольшой промежуток.
пример: 12[]{промежуток}345[]{}678
```
```
правило → здесь: Перед «а» и «но» ставится запятая.
пример: Мы хотели пойти в кино[]{здесь} но пошёл дождь.
```

`[]{}` — место без подписи. Стрелка правила может по-прежнему указывать и на часть: `правило → класс тысяч:` упрётся в `[345]`. Выбирает автор.

### 6.3. Жёлтое на жёлтом

Четыре варианта на картинке «подписи_разбора_варианты.png»:

| | Как выглядит | Оценка |
|---|---|---|
| А. Было | жёлтые подписи прямо на жёлтом блоке | сливается, нарушает «одна фигура — одна роль» |
| **Б. Белая вкладка «пример»** (рекомендую, включено по умолчанию) | разбор внутри жёлтого блока рисуется на белой вкладке, подписи на ней жёлтые — как в сцене | Согласуется с правилом «жёлтое — запомни, белое — разберись»: разбор и есть пример. Подписи везде выглядят одинаково |
| В. Белые подписи | вкладки нет, «таблетки» подписей белые | читается, но белое сразу в двух ролях |
| Г. Скобка снизу и курсив | под частью — фигурная скобка, подпись курсивом без рамки | привычно для математики (как `\underbrace`), самое лёгкое, но слабее в ч/б и на проекторе |

В сцене подписи остаются жёлтыми на белом примере, там проблемы не было. Стиль Г можно оставить как настройку для старших классов и формул.
