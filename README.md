# ДРАКОН-ГРАФ

**Расширенная версия языка ГРАФ В. Д. Паронджанова: текстовое описание → графический конспект.**

Учитель или ученик пишет конспект обычным текстом по нескольким простым правилам — программа сама рисует графический конспект по Паронджанову: запоминатели, сравнения, классификации, разбор формул, решения по шагам.

```конспект
тема: Деление с остатком
правило → остаток: Остаток всегда меньше делителя.
пример: [17]{делимое} = [5]{делитель} · [3]{неполное частное} + [2]{остаток}
```

Пара языков: **ДРАКОН** — *как действовать* (алгоритмы), **ДРАКОН-ГРАФ** — *что знать* (понятия, правила, структура).

## Библиотека и эталон

- [`src/`](src/) — библиотека: 21 модуль (разбор, схемы, раскладка, текст, SVG, подсказки); сборка — `dist/drakon-graf.js`.
- [`graf/`](graf/) — 249 эталонных рисунков и автотесты.

```bash
npm install
npx playwright install chromium
npm test        # сверка с эталоном, геометрия, типографика
npm run build   # собрать галерею graf/konspekt_v8.html
```

Шрифты: текст — **PT Serif**, код — **PT Mono** (ПараТайп), формулы и математические знаки — **Asana Math**; все три под лицензией SIL OFL 1.1 и лежат в `graf/fonts`. Принцип проекта: где возможно — российские разработки, иначе — свободные проверенные международные; и чем меньше шрифтов, тем лучше. Ширину текста библиотека считает по таблицам метрик (`src/text/metrics.js`), поэтому рисунок не зависит от машины, а сверка с эталоном точная, до байта. Геометрическая проверка смотрит на нарисованные знаки, поэтому её запускают со шрифтами эталона: `FONTCONFIG_FILE=graf/tests/fonts/fonts.conf` (так делает автопроверка GitHub). Пересборка таблиц: `npm run metrics`.

Библиотека строится по [ТЗ 0.9](docs/library/ТЗ_библиотеки_0.9.md): выполнены этапы 1 (модули), 2 (таблицы метрик, рисование в Node без браузера) и 3 (формулы через MathJax 4 со шрифтом Asana Math); 4 (обвязка: `run()`, плагин markdown-it, командная строка, страница примеров `demo/`); пакет **0.9.0 выпущен в npm**: https://www.npmjs.com/package/drakon-graf

## Как подключить

**На сайт** — три строки, всё с CDN jsDelivr:

```html
<pre><code class="language-конспект">тема: Деление с остатком
правило → остаток: Остаток всегда меньше делителя.
пример: [17]{делимое} = [5]{делитель} · [3]{неполное частное} + [2]{остаток}</code></pre>

<script src="https://cdn.jsdelivr.net/npm/drakon-graf@0.9/dist/drakon-graf.min.js"></script>
<script>window.MathJax = drakonGraf.mathjaxConfig();</script>
<script src="https://cdn.jsdelivr.net/npm/@mathjax/mathjax-asana-font@4.1.3/tex-mml-svg-mathjax-asana.js"></script>
<script>drakonGraf.run({ hints: true });</script>
```

MathJax нужен только для формул `$…$`; без него формулы рисуются простым текстом.

**В Node и сборщиках:** `npm install drakon-graf`

```js
import { render, ready } from 'drakon-graf';
await ready();                                        // MathJax для формул
const { svg, hints } = render(text, { width: 680, class: 7 });
```

**Markdown (markdown-it):** `md.use((await import('drakon-graf/markdown-it')).default)` — блок ```` ```конспект ```` становится рисунком.

**Командная строка:**

```bash
npx drakon-graf урок.md -o рисунки/      # все блоки «конспект» → SVG
npx drakon-graf --check урок.md          # только подсказки (код выхода 1, если есть «важно»)
```

Живой пример — [`demo/index.html`](demo/index.html). Типы для TypeScript — `index.d.ts`.
