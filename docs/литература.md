# Список литературы проекта ДРАКОН-ГРАФ

Это рабочий список для будущей статьи. Сюда попадает каждый источник, на который мы опирались. Оформление близко к ГОСТ Р 7.0.100-2018.

**Пометки:**
- **[Ц]** — прочитан целиком;
- **[Ф]** — прочитаны фрагменты;
- **[С]** — использован по ссылке или цитате у других авторов, первоисточник не читали;
- **→** — где источник использован в проекте.

Пополняется при каждом новом разборе. Последнее обновление — 01.11.2026.
