Правило с разбором формулы

тема: Деление с остатком
правило → остаток: Остаток всегда меньше делителя.
пример: [17]{делимое} = [5]{делитель} · [3]{неполное частное} + [2]{остаток}

Формулы

тема: Квадратное уравнение
класс: 8
правило: Корни $x_{1,2}=\frac{-b\pm\sqrt{D}}{2a}$, где $D=b^2-4ac$.
  $$x_1 + x_2 = -\frac{b}{a}, \quad x_1 x_2 = \frac{c}{a}$$
пример: $x^2-5x+6=0$, $D=1$, $x_1=2$, $x_2=3$

Запоминатели (ГНОМ)

тема: Части речи
Существительное -> Это часть речи, которая обозначает предмет.
Прилагательное -> Это часть речи, которая обозначает признак предмета.
Глагол -> Это часть речи, которая обозначает действие предмета.

Очная ставка

тема: Не путать: НОД и НОК
НОД — наибольший общий делитель. НОД(12, 18) = 6 >< НОК — наименьшее общее кратное. НОК(12, 18) = 36
