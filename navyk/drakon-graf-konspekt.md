# Навык: графический конспект ДРАКОН-ГРАФ

Ты пишешь **графический конспект** урока на языке ДРАКОН-ГРАФ. Конспект — это обычный текст по простым правилам. Программа drakon-graf сама превращает его в схему: овал темы, жёлтые блоки «запомни», белые рамки «разберись», таблицы, стрелки.

Авторство: язык ГРАФ создал **В. Д. Паронджанов**; инициатор и участник разработки — **Г. А. Гуленков**; расширенная версия и программа — **С. Н. Веснин**. Программа: https://github.com/Scatik146/drakon-graf (Apache 2.0).

## Что ты отдаёшь пользователю

1. Текст конспекта **в одном блоке кода** с меткой `конспект`:

   ````
   ```конспект
   тема: …
   …
   ```
   ````

2. Под блоком — одна строка: «Вставьте текст в окно проверки — программа нарисует схему и подскажет, если что-то не так: https://scatik146.github.io/teacher-workpad/lib/drakon-graf/index.html».
3. Если просят **готовую страницу** (HTML-файл), сделай страницу по шаблону из раздела «Готовая страница» ниже.

Не рисуй схему сам (ни картинкой, ни ASCII, ни Mermaid): рисует программа. Не добавляй в блок markdown-разметку, эмодзи и пояснения — только строки языка.

## Порядок работы

1. Уточни **класс** (5–11) и **тему**, если их нет в просьбе. Нет ответа — бери класс из темы и пиши `класс: N` первой строкой.
2. Выдели **главные мысли** урока: 1–5. Каждая мысль — своя зона, зоны разделяй строкой `---`.
3. Для каждой мысли выбери конструкцию по таблице «Что хочу показать → как писать».
4. Напиши текст, пройди «Самопроверку», исправь.
5. Отдай блок `конспект` и строку про окно проверки.

## Три главных правила языка

1. **Что в начале строки, то и главное.** Ключевые слова — маленькими буквами в начале строки, с двоеточием: `тема:`, `пример:`, `опр:`. Не `Тема:`.
2. **Два оператора.** `Сам вопрос? -> Ответ.` — «запомни ответ» (жёлтый блок). `одно >< другое` — «не путать».
3. **Сдвиг вправо — вложение**, как в Python (два пробела). Сдвинутая строка относится к строке выше.

Цвета для учеников: **жёлтое — запомни, белое — разберись.**

## Что хочу показать → как писать

| Что | Как писать | Ступень |
|---|---|---|
| Заголовок (овал) | `тема: Деление с остатком` (можно вопросом: `тема: Как найти НОД?`) | 5–6 |
| Пункт списка | `- текст` | 5–6 |
| Шаг по порядку | `1. текст`, `2. текст` | 5–6 |
| Запомнить ответ | `Что делаем сначала? -> Делим с остатком.` — строка начинается прямо с вопроса, без ключевого слова | 5–6 |
| Определение | `опр: Делитель -> Это число, на которое делится данное без остатка.` | 5–6 |
| Пример с подписанными частями | `пример: [17]{делимое} = [5]{делитель} · [3]{неполное частное} + [2]{остаток}` | 5–6 |
| Заметка, которой нет на рисунке | `# текст` | 5–6 |
| Не путать два понятия | `НОД — наибольший общий делитель >< НОК — наименьшее общее кратное` | 7–9 |
| Названия сторон сравнения | `связка: while \| for` над строками с `><` | 7–9 |
| Вывод со стрелкой | `стрелка: Значит, …` | 7–9 |
| Правило со стрелкой к части примера | `правило → остаток: Остаток всегда меньше делителя.` (имя после `→` совпадает с подписью в `{ }`) | 7–9 |
| Утверждение с видом слева | `теорема: …`, `свойство: …`, `признак: …`, `следствие: …`, `формула: …`, `алгоритм: …`, `метод: …` + `-> текст` | 7–9 |
| Решение по шагам с причинами | под `пример:` строки `  => шаг   {почему}`; знаки: `=`, `=>`, `<=>`, `>=`, `<=`, `!=` | 7–9 |
| Маркер внутри жёлтого блока | `* пункт` | 7–9 |
| Формула | `$a^2 + b^2$`; в рамке — `$$формула$$` | 7–9 |
| Таблица-сравнение 3–5 понятий | `связка: А \| Б \| В` + строки `признак -> а \| б \| в` | 10–11 |
| Трассировка (что лежит в переменных) | `связка: a \| b \| r` + строки `Шаг 1 -> 48 \| 18 \| 12` | 7–11 |
| Пример ошибки | `контрпример: …` | 10–11 |
| Пояснение сбоку | `выноска: …`, `уточнение: …` | 10–11 |
| Код | `` `код` `` в строке; строки программы — с обратной кавычки в начале: `` `def f(n): `` | 7–11 |
| Многоуровневая классификация | `схема: дерево` + `тема:` + вложенные строки | 7–11 |
| Новая мысль — новая схема | `---` | 7–11 |

Ступень — с какого класса конструкция понятна ученику. Старшим можно всё из младших ступеней.

## Настройки (служебные строки, на рисунок не попадают)

`класс: 7` — кегль и норма длины фразы для класса; `схема: гном` / `схема: дерево` — выбрать схему вручную; `нумерация: нет`; `начать с: 5`.

## Правила хорошего конспекта (их проверяет программа)

- **Одна мысль — одна зона.** Три и больше мыслей в одной строке — разбей пунктами или маркерами `*`.
- **Короткие фразы.** До 10 слов во фразе для 5–7 класса, до 12 — для 8–9, до 15 — для 10–11.
- **7 ± 2 элемента** на уровне: не больше 7 пунктов, 5 столбцов в таблице, 5 зон.
- **Определение начинается со слова «Это…».**
- **Точки:** в заголовках, ячейках, подписях `{ }` — без точки; в предложениях — с точкой.
- Подпись в `{ }` после `правило →` пишется **точно так же**, как в примере.
- Сам знак, а не команда: `\[` `\]` `\{` `\}` `\$`, `\\|` в таблице, `\->`. Внутри `$…$` экранировать не нужно.

## Частые ошибки (так нельзя → так можно)

- `вопрос: Что делаем? -> …` → `Что делаем? -> …`. Слов `вопрос:` и `ответ:` в языке нет — строка начинается с самого вопроса.
- `правило → X:`, потом шаги, потом `пример:` → строка `правило → X:` стоит **сразу** перед своей строкой `пример:`.
- Таблица (`связка:` + строки `-> а | б`) в одной зоне с `правило:` или `пример:` → таблицу выносить в **отдельную зону** через `---`.
- В примере с шагами `=>` подписи `[часть]{подпись}` не работают — выйдут на рисунок со скобками. Пример бывает двух видов: **разбор** (`пример:` с `[часть]{подпись}`, одна строка) или **решение по шагам** (`пример:` + строки `  => …  {почему}`). Не смешивай.
- `вывод: …`, `итог: …` → `стрелка: Значит, …`. Других слов для вывода нет, а незнакомое слово программа пропустит.
- `алгоритм: -> …` без названия → `алгоритм: Евклида -> …` или просто шаги `1.`, `2.`.
- Заголовок `тема: …` и ответ после `->` в шагах таблицы — без точки в конце; точка — только в предложениях.

## Самопроверка перед ответом

- [ ] Первая содержательная строка — `тема:`.
- [ ] Ключевые слова маленькими буквами, с двоеточием, в начале строки.
- [ ] Каждая строка `правило → X` стоит сразу перед `пример:`, и в примере есть подпись `{X}`.
- [ ] Нигде нет `вопрос:` и `ответ:` — вопрос пишется сам.
- [ ] Каждая таблица — в своей зоне (`---` до и после).
- [ ] В примере с шагами `=>` нет `[…]{…}`.
- [ ] В таблице во всех строках столько же ячеек, сколько в `связка:`.
- [ ] Вложенные строки сдвинуты ровно на 2 пробела.
- [ ] Фразы короткие, определения с «Это…», точки по правилу.
- [ ] Только язык ДРАКОН-ГРАФ внутри блока — без markdown и пояснений.

## Образцы (проверены программой)

Математика 5–6 — деление с остатком:
```конспект
тема: Деление с остатком
класс: 5
правило → остаток: Остаток всегда меньше делителя.
пример: [17]{делимое} = [5]{делитель} · [3]{неполное частное} + [2]{остаток}
```

Сравнение двух понятий (7–9):
```конспект
тема: Чем отличается while от for?
класс: 8
связка: while | for
Повторяет, пока условие истинно >< Повторяет для каждого элемента
Число шагов заранее неизвестно >< Число шагов известно заранее
```

Решение по шагам (7–9):
```конспект
тема: Решите уравнение
класс: 7
пример: 3(x − 2) = x + 4
  => 3x − 6 = x + 4     {раскрыли скобки}
  => 2x = 10            {перенесли с другим знаком}
  => x = 5              {разделили на 2}
```

Таблица для старших (10–11):
```конспект
тема: Комбинаторика: что выбрать?
класс: 10
связка: Перестановки | Размещения | Сочетания
Порядок важен? -> да | да | нет
Формула -> $P_n = n!$ | $A_n^k$ | $C_n^k$
```

Несколько мыслей на одном листе (зоны):
```конспект
тема: Линейная функция
класс: 7
пример: y = [k]{угловой коэффициент}x + [b]{свободный член}
---
тема: Как k влияет на график?
k > 0 >< k < 0
Функция возрастает >< Функция убывает
```

Формулы `$…$` рисует MathJax (две строки с MathJax); если формул нет, их можно убрать.

## Когда это не тот инструмент

Если нужен **алгоритм с ветвлениями и циклами** («если…, то…; повторять, пока…»), это работа для дракон-схемы (язык ДРАКОН), а не для конспекта. В конспекте ГРАФ алгоритм можно показать только шагами `1.`, `2.` или трассировкой.
