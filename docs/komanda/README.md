## 2. Правила работы (для всех помощников)

- Всё по-русски: тексты, интерфейсы, сообщения коммитов.
- Перед правкой прочитать `CLAUDE.md` и README нужного репозитория. Они главнее этого файла.
- Никаких CDN в материалах уроков: всё по относительным путям внутри сайта. Исключение — формулы MathJax в генераторе на GitHub Pages.
- Каждую схему и каждый конспект проверять программой:
  - `node tools/konspekt.mjs --scan файл --class N` (конспект);
  - `node tools/drakon-shema.mjs --scan файл` (дракон-схема);
  - и смотреть рисунок в браузере.
- Не придумывать синтаксис языка: справочники — `docs/graf/`, навык — `navyk/drakon-graf-konspekt.md`, канон ДРАКОНа — `docs/research/08_ДРАКОН_язык_разбор.md`.
- Изменения — через ветку и Pull Request; учитель смотрит и сливает. Прямо в `main` пишет только Claude по прямой просьбе учителя.
- Каждый новый источник записывать в `docs/литература.md`, каждое решение — в раздел 4 этого файла.
- Все помощники ведут `SOSTOYANIE.md` и `BRIFING.md`: прочитать перед работой; после задачи — обновить состояние и дописать итог строкой в журнал брифинга под датой.
