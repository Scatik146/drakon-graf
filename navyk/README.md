# Навык для ИИ: графический конспект ДРАКОН-ГРАФ

Один файл — и нейросеть умеет писать графические конспекты на языке ДРАКОН-ГРАФ: тему, понятия, правила, сравнения, разбор формул, решения по шагам. Нейросеть пишет текст конспекта, программа drakon-graf превращает его в схему.

## Как подключить

**Любая нейросеть (Алиса, GigaChat, Qwen, DeepSeek, GLM, ChatGPT, Claude…)**

1. Скачайте файл [`drakon-graf-konspekt.md`](drakon-graf-konspekt.md) (кнопка «Download raw file» на странице файла).
2. Прикрепите его к чату — перетащите в окно или нажмите скрепку.
3. Напишите просьбу, например: *«По этому навыку сделай графический конспект для 7 класса: НОД, алгоритм Евклида и его варианты»*.
4. Скопируйте текст из ответа и вставьте его в окно проверки — программа нарисует схему и подскажет, если что-то не так: https://scatik146.github.io/teacher-workpad/lib/drakon-graf/index.html

Если чат не принимает файлы, откройте файл, скопируйте всё содержимое и вставьте в начало сообщения.

**Claude — навсегда, без прикрепления к каждому чату**

Скачайте [`drakon-graf-konspekt.zip`](drakon-graf-konspekt.zip) и загрузите: Customize → Skills → «+» → Create skill → Upload a skill. После этого навык включается сам, когда вы просите графический конспект.

## Где посмотреть схему

- [Окно проверки](https://scatik146.github.io/teacher-workpad/lib/drakon-graf/index.html): вставьте текст — справа появится схема и подсказки.
- Или попросите у нейросети «готовую страницу» — она сделает HTML-файл, который рисует конспект в браузере (нужен интернет).
