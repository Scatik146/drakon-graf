ДРАКОН-ГРАФ

Язык графических конспектов. Пишете конспект обычным текстом по нескольким простым правилам — программа рисует схему по Паронджанову: тема в овале, «запомни» в жёлтых блоках, «разберись» в белых рамках, сравнения, разбор формул, решения по шагам.

Расширенная версия языка ГРАФ В. Д. Паронджанова. Пара языков: ДРАКОН — как действовать (алгоритмы), ДРАКОН-ГРАФ — что знать (понятия, правила, структура). Для школьников и учителей всех предметов.

Открыть генератор Конспект руками ИИ Исходный код на GitHub

Как выглядит запись

```конспект
тема: Деление с остатком
правило → остаток: Остаток всегда меньше делителя.
пример: [17]{делимое} = [5]{делитель} · [3]{неполное частное} + [2]{остаток}
```

Вставьте этот текст в генератор — справа появится схема. Печать на A4, картинки PNG и SVG, ссылка на готовый конспект.

Описание языка и учебные материалы

Справочник учителя

Для взрослых: от задачи урока к конспекту — что хотите показать и какой образец скопировать.

Шпаргалка ученика

Для детей: «пишу → получаю», по ступеням 5–6, 7–9, 10–11 классов.

Формальное описание языка

Лексика, грамматика EBNF, фигуры, 17 схем, правила раскладки, подсказки. Для разработчиков.

Текстовая запись ДРАКОН-схем

Блок дракон в markdown: одна строка — одна икона; схему рисует виджет С. Митькина.

Навык для ИИ: конспекты руками нейросети

Один файл с правилами языка, порядком работы и образцами. Прикрепите его к чату с любой нейросетью — Алиса, GigaChat, Qwen, DeepSeek, GLM, ChatGPT, Claude — и попросите: «По этому навыку сделай графический конспект про …». Готовый текст вставьте в генератор.

Пакет drakon-graf в npm: подключение на сайт тремя строками с CDN, плагин markdown-it (блок ```конспект становится рисунком), командная строка npx drakon-graf урок.md. Эталон — 249 примеров по математике, информатике и физике. Подробности — в README.

Для ИИ-агентов

Всё о проекте в одном текстовом файле для нейросетей: llms.txt (оглавление со ссылками) и llms-full.txt (навык, описание языка, справочник и шпаргалка целиком).
