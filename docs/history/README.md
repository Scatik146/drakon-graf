# Путь работы над расширенной версией ГРАФ (28.10–01.11.2026)

Этот раздел сохраняет историю: как язык конспектов шёл от разбора книги Паронджанова к замороженному эталону v8 и репозиторию ДРАКОН-ГРАФ. Здесь собраны этапные документы и картинки «было/стало», по которым принимались решения. Действующие документы — в `docs/graf/`. Если что-то здесь им противоречит, верна версия 8.

**Об источниках этой истории.** Сама переписка до 01.11 в рабочей среде не сохранилась. История восстановлена по этапным документам, картинкам решений, прототипам v1–v5, разделу 12 формального описания и по сохранённому резюме переписки. Цитаты заказчика взяты из этого резюме.

## Главные принципы, которые сложились по дороге

1. **Сначала текст, форма выводится.** Учитель не рисует (v1).
2. **Один язык.** ГНОМ и МОЛНИЯ — части ГРАФа (v2).
3. **Жёлтое — запомни, белое — разберись** (v3).
4. **Подсказки вместо ошибок** (v4).
5. **Вариант Б:** одна ширина в колонке, отбивки внутри фигуры (v5).
6. **Чем правее, тем хуже; минимум пересечений; без лишних уровней** (Евклид, v6–v7).
7. **То, что от Паронджанова, не трогаем** (экспертиза, v7, Венда).
8. **Эталон и автоматическая проверка** — любое изменение движка сверяется с 249 рисунками (v8).
