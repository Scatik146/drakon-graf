# ГРАФ. Шпаргалка ученика

*Язык ГРАФ придумал В. Д. Паронджанов; расширенная версия — С. Н. Веснин.*

*Конспект пишется словами, а картинку рисует программа. Пиши между строками ```` ```конспект ```` и ```` ``` ````.*

---

## Ступень 1. 5–6 класс

| Пишу | Получаю |
|---|---|
| `тема: Дроби` | овал-заголовок сверху |
| `- пункт` | жёлтый блок, пункт списка |
| `1. шаг` | шаг по порядку |
| `вопрос -> ответ` | слева вопрос, справа ответ: **запомни** |
| `опр: Дробь -> Это …` | «Что такое дробь» → определение |
| `пример: …` | белая рамка: **разберись** |
| `[часть]{подпись}` | часть в кружке и подпись к ней |
| `# заметка` | на картинку не попадёт |

**Запомни:** жёлтое — запомни, белое — разберись.

**Попробуй:**
```
тема: Как называются числа при сложении?
пример: [15]{слагаемое} + [7]{слагаемое} = [22]{сумма}
```

## Ступень 2. 7–9 класс

Всё из ступени 1, и ещё:

| Пишу | Получаю |
|---|---|
| `одно >< другое` | «не путать»: две стороны сравнения |
| `связка: А \| Б` | названия сторон или общий заголовок |
| `стрелка: Значит, …` | вывод со стрелкой |
| `правило → часть: …` | правило со стрелкой к части примера |
| `  => шаг решения  {почему}` | решение по шагам (выкладка) |
| `теорема: …`, `свойство: …`, `признак: …` | вид утверждения слева |
| `* пункт внутри блока` | кружок-маркер внутри жёлтого блока |
| `$x^2$` | формула |
| `---` | новая мысль — новая схема |
| сдвиг строки вправо | строка вложена в строку выше (как в Python) |

**Знаки в решении:** `=`, `=>` (⇒), `<=>` (⇔), `>=` (≥), `<=` (≤), `!=` (≠).

**Попробуй:**
```
тема: Решите уравнение
пример: 2x + 3 = 11
  => 2x = 8     {перенесли 3}
  => x = 4      {разделили на 2}
```

## Ступень 3. 10–11 класс

Всё из ступеней 1 и 2, и ещё:

| Пишу | Получаю |
|---|---|
| `связка: А \| Б \| В` + `признак -> а \| б \| в` | таблица-сравнение (Шеренга) |
| `связь А → Б: …` | стрелка связи между частями примера |
| `контрпример: …` | пример ошибки ✗ |
| `выноска: …`, `уточнение: …` | пояснение сбоку |
| `` `код` ``, `код: …` | строка кода |
| `$$формула$$` | формула в рамке |
| `схема: дерево` | выбрать схему самому |
| `[]{здесь}` | указать на пустое место |
| `\[`, `\{`, `\\|`, `\$` | сам знак, а не команда |

**Попробуй:**
```
тема: Комбинаторика: что выбрать?
связка: Перестановки | Размещения | Сочетания
Порядок важен? -> да | да | нет
Формула -> $P_n = n!$ | $A_n^k$ | $C_n^k$
```

## Если программа подсказывает

| Подсказка | Что сделать |
|---|---|
| «длинное предложение» | разбей фразу на две |
| «три и больше мыслей» | раздели маркерами `*` |
| «начинается с маркера, поэтому «->» как текст» | убери `-` в начале строки |
| «не может стоять внутри… — проверьте отступ» | сдвинь строку левее |
| «не найдена часть …» | проверь, что подпись в `{ }` написана так же |
| «нет строки «тема:»» | добавь заголовок |

**Главное:** ключевые слова пишутся маленькими буквами в начале строки: `тема:`, а не `Тема:`.
