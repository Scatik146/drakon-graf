# StepInDev: что можно взять

Проверено 13.11.2026: `github.com/step-in-dev/release` (лицензия MIT), заметки о выпусках `release-notes/ru/release-notes.md`.

## Что в репозитории
- Только заметки о выпусках и картинки. **Исходного кода сайта и интерпретатора там нет**; офлайн-сборки лежат архивами в «Releases». MIT распространяется на содержимое репозитория — то есть на заметки, не на программу. Код StepInDev без разрешения авторов брать нельзя.
- Плакаты-памятки по Роботу на Python — `step-in-dev/teachingMaterials` (лицензию проверить, если понадобятся).
- С 19.05.2026 их Робот есть модулем для обычного Python — пригодится ученикам дома (условия распространения — уточнить у авторов).

## Как у них работает `input()` (подтверждено 13.11: форк `step-in-dev/skulpt`)
По заметкам от 12.10.2024: `print` и `input` пишут в панель под редактором; интерпретатор «реализует стандарт не на 100 %» — нет моржового оператора и `f"{x=}"`, нет работы с файлами; есть пошаговое выполнение с просмотром переменных и Черепаха в браузере. Так ведёт себя **Skulpt** — Python, переписанный на JavaScript (MIT): он умеет останавливать программу на `input()` без общей памяти и заголовков.

## Варианты для онлайн-версии «Живого конспекта»
| | Skulpt (как, вероятно, у StepInDev) | Pyodide в воркере |
|---|---|---|
| Что это | Python на JavaScript | настоящий CPython в WebAssembly |
| `input()` в консоли | да, просто | да, через SharedArrayBuffer и coi-serviceworker на GitHub Pages |
| Черепаха | есть своя | нужно делать |
| Пошагово, переменные | есть | сложнее |
| Совпадение с IDLE и ЕГЭ | не полное | полное |
| Вес | лёгкий | ~10 МБ при первом запуске |

## Остальные репозитории (проверено 13.11)
| Репозиторий | Лицензия | Что там | Что берём |
|---|---|---|---|
| `skulpt` | MIT (Skulpt Project) | их форк Skulpt 1.2.0; последний коммит 21.09.2026 — убран `jseval`, чтобы программа ученика не могла выполнять JavaScript; `turtle.js`, ввод через `Sk.inputfun` | можно взять целиком (сохранив LICENSE) — уже настроен под школу |
| `robot` | MIT (В. Терещук, 2026) | Робот для настольного Python: окно, редактор обстановок, задачи; команды английские (`move_right()`, `paint()`, `is_wall_left()`) | для офлайн-версии и дома; команды не совпадают с КуМиром/ОГЭ — нужен русский слой |
| `teachingMaterials` | CC-BY-4.0 | плакаты-памятки по Роботу | можно печатать и включать в уроки с указанием авторства |
| `assets` | не указана | картинки примеров | не берём |

## Что берём
- Идеи: консоль под редактором, пошаговое выполнение с переменными, редактор обстановок, запрет копирования справки.
- Код сайта — нет (его нет в открытом доступе). Открытые части — по таблице выше.
