# Эксперимент 1: ДРАКОН-ГРАФ и настоящий Forth

Цель: проверить, что настоящий Forth запускается в браузере без интернета и без CDN, и на нём можно писать
маленькие слова на материале ДРАКОН-ГРАФ (стек, словарь, откат, переопределение, данные библиотеки).
Переход словаря на Forth — позже, при 20–30 проверенных словах (журнал `docs/komanda/README.md` § 4, 15.11).

## Выбор Forth

Сравнение Forthly и wasm-forth — по данным их страниц на GitHub из прошлого чата; запуск не проверяла. Выбор WAForth подтверждён запуском: 20 тестов из 20 (под Node и в браузере).

## Файлы
- `index.html` — страница-стенд. Загружает Forth из `lib/`, по кнопке гонит 20 тестов, показывает «прошёл / нет», время загрузки и время тестов.
- `tests.js` — 20 тестов и их запускалка (общая для страницы и Node).
- `run-node.cjs` — запуск тех же тестов под Node: `node run-node.cjs`.
- `lib/` — WAForth 0.20.1 без правок: `index.js` (JS-оболочка с вшитым WebAssembly), `index.js.map`, `waforth.d.ts`, `LICENSE` (MIT, Remko Tronçon). Получен из npm-пакета `waforth@0.20.1`.

## Как запустить
Страница работает только через веб-сервер (GitHub Pages), не из файла: `fetch` с `file://` браузер не пустит.
Откройте `…/experiments/forth/` на сайте и нажмите **«Запустить 20 тестов»**. Все пути относительные, внешних запросов нет.

## Что показали тесты (20 из 20)
- Стек: `OVER`, `ROT`, `DEPTH`; после ошибки стек очищается.
- Слова с русскими именами работают: `: ШАМПУР …`, `1 CONSTANT ТЕМА`. Имена регистрозависимы, стандартные слова — только заглавными (`DUP`, не `dup`).
- `MARKER` откатывает слова и переменные, определённые после метки; старое не трогает.
- Переопределение слова **молча** проходит; старые слова, скомпилированные раньше, хранят прежнее определение. Предупреждение сделано своим словом `ВНИМАНИЕ` на `BL WORD FIND` (тест 14).
- **Порядка поиска словарей нет** (`WORDLIST`, `ALSO`, `ORDER`, `GET-ORDER` не определены, тест 17). Порядок «урок → курс → общий» сделан как данные: три ячейки и слово `НАЙТИ` (тест 16).
- Библиотека как данные: шампур — таблица шагов, развилка — слово на `ROT IF … ELSE … THEN`, цикл ПОКА — `BEGIN … WHILE … REPEAT`.

## Оговорка к тесту 17
Тест 17 проходит именно потому, что слова `WORDLIST` нет: он фиксирует отсутствие, а не возможность.
Если порядок словарей понадобится по-настоящему (частный → общие, как в журнале 15.11), это минус WAForth:
придётся либо оставаться на «порядке как данные» (тест 16), либо искать другой Forth или дописывать словари самим.

## Ограничения WAForth (найдены запуском)
- Нет предупреждения о переопределении и нет порядка словарей (см. выше).
- `S"` и `."` работают только внутри определения `: … ;`, в режиме интерпретации — «word not supported in interpret mode». Нет `FORGET`, `[DEFINED]`, `FIND-NAME`.
- Вывод идёт побайтно (UTF-8) через `onEmit`; русский текст нужно собирать через `TextDecoder` (`tests.js` так и делает).
- `lib/index.js` — CommonJS, а не ES-модуль: страница читает его через `fetch` и запускает в `new Function`.

## Замеры
Ноутбук учителя (эталон, слабее школьных), 15.11.2026, страница на сайте, один заход: **20 из 20; загрузка Forth 240 мс; 20 тестов 88 мс** (самый долгий тест 13 мс). Браузер не указан.
Для сравнения (не ноутбук): песочница автора, headless Chrome — загрузка 93 мс, 20 тестов 49 мс; облачный браузер на сайте — 125 мс и 87 мс.
Prolog, компьютер учителя 14.11: SWI-Prolog в браузере поднялся за 1214 мс. Forth на том же эталоне загружается примерно в пять раз быстрее (240 против 1214 мс), оговорка: разные дни и не один и тот же заход.
Порог заморозки Prolog в журнале — разбор больше 3–5 с; у Forth запас большой.
