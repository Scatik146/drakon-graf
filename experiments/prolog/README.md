# Эксперимент 1: ДРАКОН-ГРАФ на Prolog

Цель: проверить, можно ли описать язык ДРАКОН-ГРАФ на Prolog так, чтобы одно описание
и разбирало строки, и порождало их, и проверяло вложенность — а JS остался корпусом.

## Файлы
- `graf.pl` — язык на Prolog (SWI-Prolog 9): разбор строки, порождение строки, таблица «что внутри чего», проверка конспекта.
- `index.html` — страница-стенд: SWI-Prolog в браузере (swipl-wasm) рядом с текущим JS-разбором (копия `src/parse/*.js` и `src/state.js` из main лежит в `src/` рядом — только для стенда).

## Как запустить
Страница работает только через веб-сервер (GitHub Pages), не из файла: модули JS и загрузка `graf.pl` с `file://` браузер не пустит.
Откройте `…/experiments/prolog/` на сайте репозитория и нажмите три кнопки:
1. **Сравнить разбор строк** — вид каждой строки в JS и в Prolog (ожидаем 20 из 20).
2. **Самопроверка** — Prolog порождает строку из терма и разбирает её обратно (ожидаем 20 из 20 `ok`).
3. **Проверка вложенности** — ошибки отступов в JS и в Prolog (ожидаем совпадение, в примере их две).

Строка состояния покажет, за сколько миллисекунд поднялся SWI-Prolog — это ответ на вопрос о скорости на школьном ноутбуке.

## Что пока не перенесено
`$…$` и `` `…` `` внутри строк, «правило -> цели:», «теорема: …» и другие KINDS, «опр:», английские синонимы,
`$$…$$`, `}`, выкладки (`=`, `=>`, `≤` …), проверки стиля из `src/lint.js`. Это следующие шаги, если эксперимент удался.
