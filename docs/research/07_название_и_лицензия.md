# Название и лицензия: проверка (01.11.2026)

## Название

**Задача.** Имя должно показывать, что основа — ДРАКОН Паронджанова, и не конфликтовать с чужими товарными знаками и пакетами.

| Вариант | Результат проверки | Вывод |
|---|---|---|
| GRAF | Совпадает с GrAF — Graph Annotation Framework (стандарт ISO 24612). Есть npm-пакеты grafjs, graf-node; созвучие с Grafana | рискованно |
| GRAPH | слишком общее слово, не регистрируется и не ищется | не подходит |
| DRAGON-… | Dragon — товарный знак Nuance/Microsoft (Dragon NaturallySpeaking) | рискованно |
| **DRAKON-GRAF / ДРАКОН-ГРАФ** | конфликтов не найдено | **принято** |

Принято: полное имя — **«Расширенная версия языка ГРАФ»**, краткое — **ДРАКОН-ГРАФ** (drakon-graf). В README и NOTICE есть оговорка: независимый проект, не связан с DrakonHub и Drakon.Tech (С. Митькин).

## Лицензия

**Требование заказчика.** Лицензия открытая; продукт можно встраивать в коммерческие разработки так же легко, как KaTeX или mermaid; ссылка на В. Д. Паронджанова (автора оригинального языка), Г. А. Гуленкова (инициатора и участника разработки) и С. Н. Веснина обязательна.

**Решение:**
- **код** — Apache License 2.0. Указание авторства закреплено в файле NOTICE. По п. 4(d) лицензии NOTICE обязателен к сохранению в производных работах, а п. 6 не передаёт права на название;
- **документация** (`docs/`) — CC BY 4.0. Это ссылка на авторов при любом использовании.

MIT отклонена: она не требует переносить NOTICE, поэтому указание авторов могло потеряться.

*Ограничение проверки.* Это поиск по открытым источникам, а не юридическое заключение. Перед регистрацией товарного знака нужна проверка по базам Роспатента и WIPO.
