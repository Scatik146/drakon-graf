# ДраконТех С. Митькина: что взять для наших дракон-схем

*Прочитаны страницы сайта https://stepan-mitkin.github.io/drakon.tech.desktop/ru/ (13.11.2026): главная, «Синтаксис языка ДРАКОН», «Как программировать на ДРАКОНе», «ДРАКОН-JavaScript», «ДРАКОН-КуМир», «Конечные автоматы». Картинки страниц прочитать не удалось, видны только подписи к ним. Поэтому то, что изображено на рисунках (например, пишется ли что-то в нижней крышке цикла), не проверено.*

Митькин — автор DrakonWidget, на котором мы рисуем. ДраконТех — его среда, где по дракон-схеме генерируется код на JavaScript, Lua, Си, Clojure, OneScript (1С), Перфоленте и **КуМире**. Сам ДраконТех, DrakonWidget и DrakonHub написаны на ДРАКОНе.

## 0. Главное для нас

1. **break — это не слово, а линия.** Ни у Паронджанова, ни у Митькина нет оператора break. Досрочный выход делают иконой Вопрос внутри цикла. Её выход ведёт **только в точку сразу после цикла**. Если направить его в другое место, получится ошибка, и на сайте это показано на двух картинках: неправильный и правильный ранний выход. Генератор Митькина break не поддерживает. return внутри цикла разрешён.

   Для нас это значит: **на картинке — линия, в тексте ввода — слово.** Текст не умеет рисовать линии, поэтому слово нужно. Варианты — в разделе 2.
2. **Цикл ДЛЯ у Митькина записывается одной строкой в верхней иконе**, по правилам целевого языка:
   - `item; array` — перебор массива;
   - `key, item; map` — перебор объекта;
   - `i = 0; i < count; i++` — for из трёх частей, как в C и Java;
   - в КуМире текст иконы переносится в код как есть, а `нц` дописывается само («для i от 1 до n», «пока …»).

   Отдельной иконы foreach нет: это та же икона ДЛЯ. Вывод: всё про цикл стоит **в верхней крышке**, у Паронджанова так же. Расходятся они в нижней крышке. У Паронджанова там «Конец цикла k», и пустой её оставлять запрещено (`docs/research/08`, § 5).
3. **НЕ и ≠ в Вопросе не нужны:** «Да» и «Нет» меняются местами одной командой (рокировка). Это та же подсказка Д18 из `docs/research/08`.
4. **«И» и «ИЛИ» — визуальные формулы.** В Вопросе пишут `A И B И C`, а рисуется цепочка Вопросов. Здесь Митькин записывает формулу текстом, а картинкой показывает её смысл. **Для нашей текстовой записи это лучший выход:** ученик пишет `вопрос: Есть молоток и есть гвоздь?`, программа рисует каноническую схему «И». Меток и переходов для этого не нужно.
5. **Цикл «делать — проверить — делать»** (do-while-do) — это гибридный цикл Паронджанова. Его стоит добавить в нашу запись.
6. **Конечный автомат = силуэт.** Каждая ветка — состояние. В начале ветки стоит Выбор `receive` с вариантами сообщений или Простой ввод, если сообщение одно: здесь автомат **ждёт**. Адрес указывает следующее состояние. Пример на сайте — лифт с пятью состояниями. Для информатики 7–9 классов это готовая тема: светофор, лифт, турникет, кодовый замок.
7. **ДРАКОН-КуМир уже существует.** Код КуМира генерируется прямо из дракон-схемы. Это подтверждает план из ТЗ (раздел 5, исполнители КуМира). Генератора на Python у Митькина нет, это наша ниша.
8. **Советы по стилю** (статья «Как программировать на ДРАКОНе»), годятся в подсказки:
   - схема не выше экрана, иначе нужен силуэт или вынос части в отдельную схему;
   - веток в силуэте не больше 10;
   - одна икона — одна мысль;
   - один вызов на строку;
   - лучше десять маленьких схем, чем одна большая;
   - **не устранять повторы любой ценой.** Иногда повтор читается легче, чем запутанные линии; дерево решений лучше, чем линия, подведённая к иконе сбоку. Здесь Митькин мягче правила Паронджанова «повторы запрещены». В подсказке это будет совет, а не ошибка.
9. **Особая ветка `catch`** — обработка ошибок в JavaScript, на неё нельзя ссылаться из других веток. Нам пока не нужна. Отмечаю как образец того, как ДРАКОН расширяют под язык программирования.
10. **Сгенерированный код руками не правят:** иначе будет «два источника истины». Это совпадает с нашим ТЗ: источник истины — текст блока, картинка из него строится.

## 1. Цикл ДЛЯ: три школы

| | Верхняя крышка | Нижняя крышка |
|---|---|---|
| Паронджанов (книги 2009, 2020) | `k` / `от k = 1 до 100` / шаг / `k ≡ смысл` | `Конец цикла k`, пустой оставлять нельзя |
| Митькин (ДраконТех) | одна строка по правилам языка: `item; array`, `i = 0; i < n; i++`, `для i от 1 до n` | по описанию пустая; на картинках не проверено |
| Мы сейчас (с 11.11) | `for x` | `in range(n)` |

**Предложение (ждёт утверждения).** Делаем по канону: всё о цикле пишем в верхней крышке на языке урока.

- Русский: `Для k от 1 до 10`, `Для каждого ученика в списке класса`.
- Python: `for x in range(n)`.
- C/Java/JavaScript: `i = 0; i < n; i++`.

Нижнюю крышку программа **заполняет сама**: «Конец цикла k» (или «Конец цикла x»). Тогда нижняя крышка не будет пустой и сразу видно, к какому циклу она относится. Учитель может вписать туда свой текст. Старая запись `{dlya, po}` остаётся для совместимости: обе части собираются в верхнюю крышку.

## 2. Досрочный выход: каким словом писать

На картинке — линия из Вопроса в точку сразу после цикла (правило Митькина и рис. 48–52 Паронджанова). В тексте — слово в ответе Вопроса:

```
для: Для каждой плюшки в кошельке
  Купи плюшку
  Съешь плюшку
  вопрос: Карлсон наелся?
    да: выход из цикла
```

| Вариант (рус.) | Англ. | Довод |
|---|---|---|
| **выход из цикла** | `break` | термин Паронджанова («досрочный выход из цикла»), понятен 5-класснику |
| прервать цикл | `break` | глагол, как в Действии |
| досрочно | `break` | коротко, но непонятно без контекста |

Тем же способом можно ввести:

- `к следующему шагу` / `continue` — линия к нижней крышке цикла. У Паронджанова continue тоже запрещён как слово, но линией он изображается законно.
- `конец` / `return` — линия к Концу схемы.

Метки «куда угодно» не вводим.

## 3. Что берём в работу (список)

- [ ] Цикл ДЛЯ по канону, нижняя крышка заполняется сама (после утверждения).
- [ ] Слова досрочного выхода: `выход из цикла` / `break`, `к следующему шагу` / `continue`.
- [ ] «И» и «ИЛИ» в Вопросе разворачиваются в цепочку Вопросов (визуальная формула).
- [ ] Гибридный цикл (делать — проверить — делать).
- [ ] Адреса в силуэте, веточный цикл; силуэт-автомат с ожиданием (Выбор или Простой ввод в начале ветки).
- [ ] Генерация кода из схемы: Python (наша ниша), позже КуМир.
- [ ] Подсказки по стилю: высота схемы, не больше 10 веток, «одна икона — одна мысль»; «повторы» — совет, а не ошибка.
