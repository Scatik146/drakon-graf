# ТЗ: JavaScript-библиотека drakon-graf, версия 0.9

*Версия ТЗ от 01.11.2026, ред. 2 (шрифты PT Serif + Asana Math, формулы через MathJax 4). Основа — формальное описание языка (`docs/graf/формальное_описание.md`) и эталон v8.3 (`graf/etalon`).*

## 1. Назначение

Библиотека превращает текст на языке ДРАКОН-ГРАФ (блок ```` ```конспект ````) в графический конспект. Подключается так же просто, как mermaid или KaTeX: одна функция, на входе текст, на выходе SVG и подсказки. Используется в «Живом учебнике», на сайтах, в Markdown-редакторах и из командной строки.

## 2. Принципы

| № | Принцип | Как выполняется |
|---|---|---|
| Б1 | **Сначала российские разработки, если их нет — свободные проверенные международные** | Текст — PT Serif, код — PT Mono (ПараТайп, OFL). Формулы и математические знаки — Asana Math (OFL) через MathJax 4 (Apache-2.0): российских аналогов такого уровня нет. **Чем меньше шрифтов, тем лучше**: три шрифта, у каждого своя роль |
| Б2 | **Эталон — закон** | Любая версия рисует 249 примеров эталона так же, как прототип. Расхождение — ошибка или осознанное изменение по решению заказчика |
| Б3 | **Одинаковый результат везде** | Ширина текста считается по таблицам метрик встроенных шрифтов, а не браузером. Поэтому Chrome, Firefox, Node и Windows дают одинаковую раскладку |
| Б4 | **Подсказки вместо ошибок** | `render` никогда не бросает исключение из-за текста конспекта. Любой текст даёт рисунок и список подсказок |
| Б5 | **Минимум зависимостей** | Во время работы — только MathJax 4 (и его шрифт Asana). Всё остальное собственное |
| Б6 | **Авторство сохраняется** | NOTICE (Паронджанов, Гуленков, Веснин) и лицензии шрифтов входят в пакет |

## 4. Программный интерфейс

```js
import { render, parse, version } from 'drakon-graf';

const r = render(text, {
  width: 680,          // ширина схемы, px (по умолчанию 680; строка `ширина:` в тексте сильнее)
  theme: 'color',      // 'color' | 'bw'
  class: 7,            // класс (строка `класс:` в тексте сильнее)
  fonts: 'link',       // 'link' — ссылка на шрифты пакета; 'embed' — шрифты внутри SVG; 'none'
});

r.svg      // строка SVG
r.width, r.height
r.scheme   // 'батарея', 'шеренга + сцена', …
r.hints    // [{ code: 'Н14', line: 5, level: 'совет' | 'важно', text: '…' }]
r.model    // дерево конспекта: строки, роли, фигуры с координатами (для редактора и доступности)

parse(text) // только разбор: дерево и подсказки, без раскладки
```

**В браузере без сборщика:**
```html
<script src="…/drakon-graf.min.js"></script>
<script>drakonGraf.run();</script>   <!-- рисует все <pre><code class="language-конспект"> на странице -->
```
Классы блока: `language-конспект` и `language-drakon-graf`.

**markdown-it:** `md.use(require('drakon-graf/markdown-it'))` — блок ```` ```конспект ```` становится SVG.

**Командная строка:**
```bash
npx drakon-graf урок.md -o рисунки/   # все блоки «конспект» из Markdown — в SVG
npx drakon-graf схема.txt > схема.svg  # один конспект
npx drakon-graf --check урок.md        # только подсказки (для учителя и проверок)
```

**Доступность.** В SVG есть `<title>` (тема схемы) и `<desc>`: текст конспекта по порядку чтения — для экранных дикторов.

## 5. Устройство

Прототип (`graf/engine.js`, 830 строк; теперь `docs/history/prototypes/v8_engine.js`) держится на общих переменных: кегль, палитра, список подсказок, счётчик ГНОМа. В библиотеке он делится на модули с чистыми функциями. Состояние одного вызова передаётся явно, в объекте контекста.

| Модуль | Что делает | Раздел формального описания |
|---|---|---|
| `lexer` | строки, отступы, ключевые слова, синонимы, экранирование | 2 |
| `parser` | классификация строк, приоритет разбора, дерево конспекта, вложение | 3, 5 |
| `schemes` | выбор схемы | 6.3 |
| `layout/*` | по файлу на схему: ГНОМ, хребет, Линейка, Гребенка, Эполеты, Очная ставка, Дерево, Шеренга, Сцена; разбор и подписи (Р16–Р21) | 6.2, 7 |
| `text` | метрики, перенос по словам и слогам, неразрывные связки, концевые строки | 7.5 |
| `math` | `$…$`, `$$…$$`, степени и индексы через MathJax 4 (шрифт Asana Math): размеры и вывод | 2.7 |

| `lint` | подсказки Н1–Н28 | 9 |
| `api` | `render`, `parse`, `run`, markdown-it, CLI | — |

Язык — JavaScript (ES2020, модули ESM), типы для TypeScript — `index.d.ts`.

## 6. Шрифты и метрики

Решение заказчика 01.11.2026: **чем меньше шрифтов, тем лучше**, засечки допустимы и в тексте. Сравнение вариантов — `docs/history/img/v8.2_запасной_шрифт_и_Asana.png`, `v8.3_засечки_часть1.png`, `…часть2.png`, `docs/history/v8.3_было_стало.html`.

| Шрифт | Роль | Лицензия |
|---|---|---|
| **PT Serif** (ПараТайп) | весь текст конспекта; обычный, жирный, курсив | SIL OFL 1.1 |
| **PT Mono** (ПараТайп) | код | SIL OFL 1.1 |
| **Asana Math** (А. Сиропулос) | формулы, греческие буквы, стрелки, знаки ∈ ∠ ⊥ ∩ | SIL OFL 1.1 |

- **Таблицы метрик** (`src/text/metrics.js`, собирает `npm run metrics`). Ширины знаков и кернинг PT Serif и PT Mono — из файлов шрифтов; ширины знаков, которых нет в PT Serif, — у Asana Math. Набор повторяет правила Chromium: кернинга нет через обычный пробел и на стыке латиницы и кириллицы, лигатуры fi и fl. Так одна схема раскладывается одинаково на любой машине.
- **Четвёртого шрифта нет.** В Asana Math нет знаков ᵏ ₙ ˣ ᵐ ᶜ ✗. С этапа 3 степени и индексы набираются формулами, а «✗» рисуется как «×» — в эталоне не осталось ни одного знака вне трёх шрифтов. Ширины этих знаков у DejaVu Sans остались в таблицах только на случай, если автор наберёт их прямо в тексте.
- **Жирного начертания у Asana Math нет**: формулы в жирных строках получают лёгкую обводку (псевдожирный). Составные знаки (x̄) набираются формулами.
- **Кегль** по классу: 15/14/13 px (Р25). Для печати — пересчёт в пункты (ТЗ «Живой учебник», 8.1).
- `fonts: 'embed'` встраивает в SVG только нужные знаки (подмножество шрифта). Такой файл самодостаточен и открывается где угодно.

## 7. Формулы

- `$…$` в строке и `$$…$$` выключные — через **MathJax 4** со шрифтом **Asana Math** (`@mathjax/mathjax-asana-font`), подмножество ТЗ 8.1. Степени и индексы в обычной записи (`a^n`, `x_0`) — тоже через формулы.
- **Вывод — чистый SVG** (MathJax SVG output): без `<foreignObject>`, поэтому формула одинакова в браузере, в Node и при печати, и открывается в любых программах.
- **Размер формулы** известен сразу из вывода MathJax: в браузере и в Node он один и тот же.
- **Риск — размер и скорость.** MathJax тяжелее KaTeX в несколько раз и набирает медленнее. На этапе 3 замеряются: размер пакета, время набора конспекта (п. 8.5). Если не уложимся — загрузка MathJax только для конспектов с формулами.

## 8. Проверка и приёмка

1. **Эталон.** 249 примеров `graf/etalon` в браузерном режиме совпадают с прототипом: текст, фигуры и переносы — точно, координаты — с допуском 3 px. Эталон v8.3 снят библиотекой по таблицам метрик (PT Serif + Asana Math), сверка точная — до байта. Формулы в эталоне набраны упрощённо, поэтому для примеров с формулами на этапе 3 снимается новый эталон: его утверждает заказчик по картинкам «было/стало».
2. **Геометрия и типографика** (`tests/geo.js`, `tests/typo.js`) — 0 замечаний на всём эталоне в браузере и в Node.
3. **Совпадение браузера и Node.** На примерах без формул раскладка одинакова: те же строки и переносы, координаты — с допуском 1 px.
4. **Модульные тесты** разбора: каждая конструкция раздела 3 и каждая подсказка Н1–Н28.
5. **Скорость.** Конспект средней сложности рисуется быстрее 30 мс в браузере, все 249 примеров — быстрее 5 с.
6. **Размер.** Ядро без шрифтов, таблиц метрик и MathJax — не больше 60 КБ в gzip.
7. **Автопроверка GitHub:** Node 20 и 22, Chromium и Firefox (Playwright).
