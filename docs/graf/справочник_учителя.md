# Расширенная версия языка ГРАФ (v8). Справочник учителя: от задачи к конспекту

*Создатель оригинального языка ГРАФ — В. Д. Паронджанов. Автор расширенной версии — С. Н. Веснин.*

*Как пользоваться: найдите в левом столбце, что вы хотите показать на уроке, и скопируйте образец. Программа сама выберет схему и нарисует конспект. Полные правила — в «Формальном описании ГРАФ v8».*

---

## Три правила, которые стоит запомнить

1. **Что в начале строки, то и главное.** `тема:` — заголовок, `-` — пункт, `1.` — шаг, `*` — маркер внутри блока.
2. **Два оператора.** `вопрос -> ответ` — «запомни ответ». `одно >< другое` — «не путать».
3. **Сдвиг вправо — вложение,** как в Python. Пример, сдвинутый под определение, рисуется под ним.

Остальное программа подскажет сама: под рисунком появятся советы, а не ошибки.

## 1. Понятия и факты

### Дать определение

```
опр: Модуль числа -> Это расстояние от нуля до точки на координатной прямой.
```
Схема: **ГНОМ** (колонка запоминателей с номерами). Начинайте определение словом «Это…», так советует Паронджанов. Если термин из одного-двух слов, слева будет «Что такое модуль числа».
*Образец в эталоне: «Модуль числа» (Алгебра 7, углубл.).*

### Несколько определений, свойств, формул подряд

```
схема: гном
класс: 7
свойство: переместительное -> $a + b = b + a$
  | От перестановки слагаемых сумма не меняется.
свойство: сочетательное -> $(a + b) + c = a + (b + c)$
свойство: распределительное -> $a · (b + c) = a · b + a · c$
  пример: 7 · 13 + 7 · 7 = 7 · (13 + 7) = 140
```
Виды указателей: `теорема:`, `свойство:`, `признак:`, `следствие:`, `формула:`, `аксиома:`, `закон:`, `метод:`, `алгоритм:`, `команда:`, `единица:`.
*Образец: «Свойства сложения и умножения» (Математика 5).*

### То же, но под общим заголовком

Добавьте `тема:`, и колонка станет **Батареей**:
```
тема: Признаки делимости
признак: на 2 -> Последняя цифра чётная: 0, 2, 4, 6, 8.
признак: на 3 -> Сумма цифр делится на 3.
  выноска: 372: 3 + 7 + 2 = 12
```
*Образец: «Признаки делимости» (Математика 5).*

### Теорема со следствиями

```
схема: гном
теорема: о сумме углов треугольника -> Сумма углов треугольника равна 180°.
  $$∠A + ∠B + ∠C = 180°$$
следствие: 1 -> В треугольнике не может быть двух тупых углов.
```
*Образец: «Сумма углов треугольника» (Геометрия 7).*

## 2. Сравнения

### Не путать два понятия

```
тема: Не путать: НОД и НОК
НОД — наибольший общий делитель >< НОК — наименьшее общее кратное
```
Схема: **Очная ставка**.

### Сравнить два понятия по нескольким признакам

```
тема: Чем отличается while от for?
связка: while | for
Повторяет, пока условие истинно >< Повторяет для каждого элемента
Число шагов заранее неизвестно >< Число шагов известно заранее
стрелка: Ввод до нуля
стрелка: for i in range(10)
```
Одна `стрелка:` — общий вывод под обеими сторонами, две — вывод под каждой.
*Образцы: «while и for» (Информатика 8), «Несовместные и независимые» (ВиС 10).*

### Сравнить 3–5 понятий по признакам (таблица)

```
тема: Законы Ньютона
связка: I закон | II закон | III закон
Суть -> Без сил — покой | Сила даёт ускорение | Действие равно противодействию
Формула -> $\vec F = 0$ | $\vec F = m\vec a$ | $\vec F_{12} = −\vec F_{21}$
```
Схема: **Шеренга**. Ячейки разделяйте ` | ` (черта с пробелами). Больше 5 столбцов программа посоветует разбить на две шеренги.
*Образцы: «Законы Ньютона» (Физика 9), «Значения тригонометрических функций» (Алгебра 10).*

### Частая ошибка

```
тема: Где ошибка?
связка: Ошибка | Верно
$(a + b)^2 = a^2 + b^2$ >< $(a + b)^2 = a^2 + 2ab + b^2$
стрелка: Причина: забыли удвоенное произведение.
```
или `контрпример:` в разборе (раздел 4).
*Образец: «Работа над ошибкой» (Петерсон 5–9).*

## 3. Классификации и списки

### Классификация в две-три группы

```
тема: Виды треугольников
По углам:
  - остроугольный
  - прямоугольный
По сторонам:
  - равнобедренный
  - равносторонний
```
Схема: **Эполеты**.

### Многоуровневая классификация

```
схема: дерево
тема: Четырёхугольники
Параллелограммы
  - прямоугольник
  - ромб
Трапеции
  - равнобедренная
```
Схема: **Дерево**. На одном уровне — не больше 7 узлов.
*Образцы: «Четырёхугольники» (Геометрия 8), «Дерево случайного опыта» (ВиС 7).*

### Короткий перечень

```
тема: Числа на координатной прямой
- Отрицательные
  выноска: левее нуля
- Ноль
- Положительные
```
Короткие пункты встанут в ряд (**Линейка**), длинные — в столбец (**Лестница**), много коротких — в колонки (**Гребенка**). Схему выбирать не нужно.

## 4. Формулы, записи, разбор

### Разобрать формулу: что означает каждая буква

```
тема: Нагревание тела
пример: Q = [c]{удельная теплоёмкость} · [m]{масса} · [$(t_2 − t_1)$]{изменение температуры}
```
Квадратные скобки — что подписать, фигурные — подпись. Программа разложит подписи так, чтобы ничего не пересекалось.
*Образец: «Количество теплоты» (Физика 8).*

### Правило со стрелкой к части примера

```
тема: Деление с остатком
правило → остаток: Остаток всегда меньше делителя.
пример: [17]{делимое} = [5]{делитель} · [3]{неполное частное} + [2]{остаток}
```

### Показать связь между частями

```
тема: Что значит a = a + 1?
правило → новое: Сначала вычисляется правая часть, потом результат кладётся в переменную.
пример: [a]{новое} = [a]{старое} + 1
  связь старое → новое: +1
```

### Указать на пустое место

```
тема: Где поставить запятую?
правило → здесь: Перед «а» и «но» ставится запятая.
пример: Мы хотели пойти в кино[]{здесь} но пошёл дождь.
```

### Решение по шагам с обоснованиями (выкладка)

```
тема: Решите уравнение
пример: 3(x − 2) = x + 4
  => 3x − 6 = x + 4     {раскрыли скобки}
  => 2x = 10            {перенесли с другим знаком}
  => x = 5              {разделили на 2}
```
Каждая строка начинается со знака: `=`, `=>` (⇒), `<=>` (⇔), `>=` (≥), `<=` (≤), `!=` (≠). Причина — в фигурных скобках в конце.
*Образцы: «Решение уравнения», «Доказательство неравенства», «Уравнение теплового баланса».*

### Контрпример

```
тема: Неравенство треугольника
теорема: Каждая сторона треугольника меньше суммы двух других.
пример: [a]{любая сторона} < [b + c]{сумма двух других}
контрпример: 2, 3, 6: 6 > 2 + 3 — такого треугольника нет
```

## 5. Алгоритмы и процессы

### Последовательность шагов

```
тема: Как сложить дроби с разными знаменателями
  уточнение: Пример: 1/4 + 1/6
1. Найти общий знаменатель — НОК знаменателей.
2. Найти дополнительные множители.
3. Умножить числители на дополнительные множители.
4. Сложить числители.
```
Схема: **Лестница**. Если в алгоритме есть ветвления и циклы, это работа для **ДРАКОНа**, а ГРАФ рядом покажет, что нужно знать.

### Трассировка: что лежит в переменных

```
тема: Трассировка: НОД(48, 18)
связка: a | b | r
Шаг 1 -> 48 | 18 | 12
Шаг 2 -> 18 | 12 | 6
Шаг 3 -> 12 | 6 | 0
стрелка: b = 0 — ответ: НОД = 6
```
В режиме «Самопроверка» ячейки скрыты, и ученик заполняет таблицу сам.

### Код с пояснением

```
тема: Рекурсивная функция
правило → база: Без базы рекурсия не остановится!
пример: [`if n == 0: return 1`]{база} · [`return n * f(n−1)`]{шаг}
---
`def f(n):
`    if n == 0:
`        return 1
`    return n * f(n - 1)
```

## 6. Несколько мыслей на одном листе

Разделяйте зоны строкой `---`: каждая зона рисуется своей схемой.
```
тема: Линейная функция
пример: y = [k]{угловой коэффициент}x + [b]{свободный член}
---
тема: Как k влияет на график?
k > 0 >< k < 0
Функция возрастает >< Функция убывает
```
Больше 5 зон программа посоветует разбить на две схемы.

## 7. Настройки

| Строка | Что делает |
|---|---|
| `класс: 6` | крупнее шрифт для младших, норма длины фразы по классу |
| `схема: дерево` | выбрать схему вручную |
| `нумерация: нет` | убрать номера в ГНОМе |
| `начать с: 5` | начать номера ГНОМа с 5 (продолжение конспекта) |

## 8. Советы Паронджанова, которые проверяет программа

| Совет | Подсказка программы |
|---|---|
| Одна мысль — одна зона | «три и больше мыслей — разбейте маркерами» |
| Определение начинается с «Это…» | «лучше начинать со слова «Это…»» |
| Короткие фразы | «длинное предложение: N слов при норме до M» (норма по классу) |
| Не больше 7 ± 2 элементов | подсказки о Батарее, Шеренге, Дереве, Линейке, зонах |
| Заголовки, ячейки, подписи — без точки; предложения — с точкой | подсказки о точках |

## 9. Если нужен сам знак

| Нужно в тексте | Пишите |
|---|---|
| `[` `]` | `\[` `\]` |
| `{` `}` | `\{` `\}` |
| `\|` в таблице | `\\|` — например, `\\|x\\|` |
| `$` | `\$` |
| `->` буквами | `\->` |
| новая строка внутри блока | `\n` |

В формулах между `$…$` ничего экранировать не нужно.
