# Брифинг — журнал

Каждый рабочий день начинается с брифинга в отдельном чате «Брифинг». Там решаем, что делаем, а потом уходим в короткие чаты, по одной задаче в каждом. В этом файле — итог каждого брифинга: повестка, решения и задачи на день с исполнителями. Записи идут сверху вниз, новая дата — сверху.

## Как начать чат «Брифинг» (вставить первым сообщением)

> Брифинг. Прочитай в репозитории Scatik146/drakon-graf три файла: `docs/komanda/SOSTOYANIE.md`, `docs/komanda/BRIFING.md` (последняя запись) и оглавление `docs/project/ТЗ_Живой_учебник.md`. Остальное — только по запросу. Работаем по навыку «экономная сессия». В конце брифинга допиши запись в `BRIFING.md`, обнови `SOSTOYANIE.md` и дай мне для каждой задачи готовое первое сообщение для отдельного чата.
